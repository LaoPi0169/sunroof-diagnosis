# ADR-004：部署层适配决策（节点 ⑤）

状态：已接受（2026-10，节点 ⑤ 实施时记录）
回链：`../fde-roadmap-v1.md` §2 节点 ⑤ · `specs/mission-week-08.md` · `adr-003`（引擎复用原则）· `decision-memo-02.md` 差距 5（无部署面）

## 背景

节点 ⑤ 要补齐发布清单、配置收敛、任务级冒烟门、CI 与回滚演练。核心张力：
节点 ②-④ 已冻结（迁移 001-003、引擎判定表、26 用例），而"配置收敛"要求存在一个
**可被部署改变的运行时参数**，且回滚演练要求配置错误能造成**任务级可观测的漂移**。

## 决策

**D1 —— 偏差硬限升为发布配置，引擎"读配置、回退默认"。**
运行时真值 = `policy_config.spec_check.hard_limit_deviation_pct`（迁移 004 种子 `15.0`）；
读取失败/缺失/非法值（非正数、非数字）一律回退引擎常量 `15.0`。理由：偏差硬限是
唯一的业务判定阈值，是最自然的"政策配置"；防御性回退保证坏配置拖不垮服务可用性
（收敛器不判对错，对错靠评审 + 冒烟双防线——引擎自己兜底）。

**D2 —— known-good 配置下行为逐字节等价，冻结面零改动。**
种子值 = 引擎原常量 = known-good 配置值（15.0），26 个既有用例零回归（实测 35/35 全绿）。
001-003 DDL、判定表、响应契约一字未动；`config_version` 标记行使配置可观测。

**D3 —— 收敛器唯一可写面 = `policy_config` 表，白名单 2 键，幂等 UPSERT，零 DDL。**
非白名单键拒绝收敛（Default-Deny）；重复收敛投影一致；业务表快照前后逐字节相等
（用例 3 锁定）。回滚时数据库兼容性由此保证（用例 7：全程零建表零删表）。

**D4 —— 冒烟打真实 uvicorn 实例（urllib + sqlite3 纯标准库），绝不用 TestClient 替代。**
`/health` 200 ≠ 业务正确：4 条冒烟全部三向对账（响应 + `spec_check_tasks` + 审计）。
SMOKE-01 同时核对节点 02 `task_runs` 血缘——部署复验必须证明血缘不断链。

**D5 —— 回滚 = 配置收敛式 + 数据版本重置，不做 DDL 降级。**
任务夹具是状态机一次性终态，复验必须全新初始化（`ROLLBACK.md` 场景 D）。
演练运行器每阶段冷部署全新实例，兼容性以三库表集合一致断言；不宣称热回滚/迁移可逆。

**D6 —— CI 单入口四阶段，本地与 GitHub Actions 同一份 `ci/run_local_ci.py`。**
STAGE-4 从 `git archive HEAD` 冷部署——因此 CI 只对**已提交**代码有意义（证据可追溯到
代码基线）；未提交变更先走分支提交。证据落 `evidence/ci-run-w08.log`，汇总进 `ci-evidence.md`。

## 后果

- 正面：部署从手工动作变成"代码基线 + 配置收敛 + 任务级冒烟"的可重复流程；配置漂移有指定检测器（SMOKE-01）与指定恢复路径（场景 A）。
- 代价：引擎每次规格核对多一次配置表读（SQLite 单机教学规模可忽略）；`HARD_LIMIT_DEVIATION_PCT` 语义从"常量"变为"默认回退值"（docstring 已注明）。
- 未做（诚实边界）：无行锁/乐观锁（沿用 decision-memo-02 差距 1）；无真实 SSO；无多环境配置矩阵（仅 known-good + 演练注入物两份）。
