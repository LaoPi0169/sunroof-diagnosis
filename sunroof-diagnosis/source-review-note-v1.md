# 来源回读记录 v1（Source Review Note）

- **回读形式**: 课程模拟知识所有者走查（无真实权限参与者；不涉及任何真实客户数据）
- **参与者保护**: 模拟角色知情且可随时纠正/停止/撤回；记录仅保留角色与结论，不保留个人身份

## 回读五问与结论

| 问题 | 结论 |
| --- | --- |
| 哪份材料是正式来源？ | service-general-v3 / torque-east-v5（一线可用）、claim-supervisor-v2（主管专属） |
| 哪个字段决定当前有效？ | effective_at/expires_at + supersedes 谱系关系，不是文件修改时间 |
| 谁能修改、下线或解决冲突？ | 对应知识所有者；冲突对（retrofit-bulletin-v2 vs retrofit-notice-v4：当场答复 vs 一律转复核）需所有者裁决后出新版本 |
| 一线遇到冲突时怎样升级？ | 沿用节点 ④ 路径：needs_review → escalate → 质量主管结案 |
| 哪些内容即使相关也禁止进入一线上下文？ | 主管例外条款（含疑似复制件）、隔离区材料、过期与冲突正文 |

## 会触发「更新语料或停止 RAG」的新证据

- 来源合同无法建立（所有者/权限持续缺失）→ 停止 RAG，回退普通搜索 + 内容治理；
- 出现 OEM 项目组维度的语料 ACL 需求 → 新建语料快照版本，不得在旧快照内静默改权限；
- 第 10 周评测发现 gold source 缺失 → 回到本周新建 corpus 版本（不在数据集背后改文档）。

## 诚实边界

本记录仅证明「语料可被治理成权限受控、可重复构建的快照」，
**不证明 RAG 会改善一线任务** —— 该问题留给第 10–12 周的冻结评测合同与只读 RAG 评测。
