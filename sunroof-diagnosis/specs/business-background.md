# 业务背景活文档（Business Background）—— 天窗总成只读诊断
版本 v1 · 阶段 A 节点 ①（W1-4 交付）· 状态：现行有效
回链：`fde-roadmap-v1.md` §2 节点 ① · `specs/discovery-brief-v1.md` · `specs/role-and-permission-matrix.md`

> 维护规则：本文档只记录**业务事实**（系统、数据、角色、风险），不记录方案；方案进 Discovery Brief / ADR / 行为合同。事实变化时更新本文件并递增版本，不覆盖历史结论。

## 1. 一句话业务背景
天窗总线 PQE（产品质量工程师）在 EOL 下线检测报出「异响 / 防夹功能误触发」故障、或接到主机厂（OEM）市场退返件条码（SN）时，需要跨 MES / QMS / PLM 三个系统人工检索数据才能完成根因分析——检索慢、易看错过期 SOP、跨主机厂敏感图纸存在越权泄露风险。

## 2. 系统与数据事实（只述事实，不述方案）
| 事实 | 内容 |
|---|---|
| MES | 按天窗 SN 保存装配与下线检测记录：拧紧扭矩（如 Bolt-03 电机固定螺栓 8.2 N·m）、ECU 刷写记录、防夹电流波形峰值与发生行程（如 12.4 A @ 220 mm） |
| QMS | 保存检验 SOP 与质量标准，带版本 / 生效 / 失效属性（如 QMS-SOP-SR-04 v5.0 于 2026-06-01 生效；v4.0 已被替代） |
| PLM | 保存 BOM 与 ECO 工程变更记录（如 PLM-ECO-2026-081-v1：电机支架垫片材质更新，BOM Rev-C） |
| 主机厂隔离 | OEM-A / OEM-B 各自的图纸、特批质量标准互为商业机密；跨项目可见即泄露事故 |
| 写路径现状 | 返修单 / 隔离单 / 报废单 / 8D 报告均在各原系统由 PQE 人工录入，系统不做任何代写 |

## 3. 角色与日流程（事实）
1. **PQE（项目组内，如 OEM-A 项目组）**：EOL 台架报警或收到退返件 SN → 登录 MES 查装配记录 → 切 QMS 查现行 SOP → 切 PLM 查 BOM/ECO → 人工对账 → 手写根因分析报告。
2. **质量主管**：处理特批例外条款、跨项目质量裁决、返修/隔离/报废的最终批准（批准动作本身在原系统人工完成）。
3. **系统/运维**：负责部署与回滚，不接触业务正文。

## 4. 风险事实（决定三条铁律的映射）
| 风险事实 | 映射铁律 |
|---|---|
| 跨 OEM 查询图纸 / 特批标准 = 商业泄露事故 | 合同先行：ACL 隔离写进问题合同，0 次越权 |
| 过期 / 已被替代 SOP 与现行版并存，人工易看错 | 证据说话：只允许引用「现行有效」来源，0 次过期引用 |
| MES 与 PLM 规格冲突 / 数据缺失时人工易"脑补" | 诚实边界：缺失、冲突、过期一律显式拒答，0 次假装知道 |
| 大模型直写 MES/QMS = 生产事故 | 范围界定：外部写效果为 0，只读诊断 |

## 5. 阶段 A 节点 ② 的领域映射（确定性薄片如何落在本业务上）
| 原型薄片（北辰客服政策核对） | 本项目对应（天窗装配规格核对） |
|---|---|
| `region` 地区 | `oem_project` 主机厂项目组（ACL 下推键） |
| `purchased_at` 购买日期 | `measured_at` 测量日期（生效窗口判定键） |
| `amount` 金额门槛 | `measured_value` 相对现行规格的偏差百分比硬限 |
| 政策唯一当前有效命中 | 规格唯一现行有效命中（part_no + process_step + 窗口 + ACL） |
| 已废弃版本拦截 | 已被替代 / 过期 SOP 永不引用（`is_current=0` 行 SQL 层排除） |
| `AMOUNT_EXCEEDS_LIMIT` | `SPEC_HARD_LIMIT_EXCEEDED`（偏差 >15% 需质量主管复核） |
| `NO_MATCHING_POLICY` | `NO_MATCHING_SPEC` |
| `POLICY_CONFLICT` | `SPEC_CONFLICT`（同零件同工序两条现行有效规格并存） |

## 6. 本仓库的模拟口径（诚实边界，不可删除）
- 本仓库为**教学模拟**：MES / QMS / PLM 以 SQLite 合成夹具模拟（`migrations/001_init_schema.sql`），无真实系统对接、无真实模型调用；
- 第 5 周薄片阶段**零大模型**：全部判定由确定性代码 + SQL 完成，`answered` 语义是「依据充分、可出具带引用的草稿」，不是「合格」；
- 文中出现的 SN / 扭矩 / SOP 编号均为构造数据，与任何真实产品无关。
