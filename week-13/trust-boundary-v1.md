# 信任边界 v1 (Week 13, 第 2 天) —— case.lookup_context@1

六分区 (手册「信任边界六分区」; 本实现为进程内教学切分):

```text
+--------------------------------------------------------------+
| (1) 已认证会话区 (可信源)                                      |
|     tenant_id / user_id / role —— Host 从登录态构造            |
|     证据: mcptool/client.py TrustedSession (演示: 周宁)         |
+--------------------------------------------------------------+
| (2) 模型/调用方提案区 (不可信输入)                              |
|     只允许 arguments = {case_id, fields}; 身份键走私即拒绝      |
|     证据: X-01 (走私参数 -> invalid_argument, 服务端 0 调用)    |
+--------------------------------------------------------------+
| (3) Host 编排区 (允许列表 + 注入 + 客户端校验)                  |
|     工具允许列表默认关闭; 版本 pin; deadline 500ms; 封套校验     |
|     证据: X-03 (version=2 -> 拒绝); R-04 (超时作废); R-05       |
+--------------------------------------------------------------+
| (4) 服务端执行区 (二次鉴权)                                     |
|     独立重做封闭校验 + 租户x角色x对象x字段四级鉴权 + 字段过滤     |
|     证据: R-03 (三因 not_available 不可区分); R-02              |
+--------------------------------------------------------------+
| (5) 受限数据区 (案例库)                                         |
|     只读合成工单库; 受限字段在库但永不在枚举; 无写入口            |
|     证据: R-01 (响应恰好 3 字段); 夹具前后快照逐字节一致          |
+--------------------------------------------------------------+
| (6) 审计与证据区 (受限)                                         |
|     run_id/caller/outcome/reason_typed/external_write_effects   |
|     证据: R-03 三类细分原因只进审计; R-05 安全事件单列            |
+--------------------------------------------------------------+
```

## 分区规则 (逐条对应合同)

1. 身份只从 (1) 流向 (3)(4), 永不经过 (2) —— 参数走私即 invalid_argument (X-01);
2. (2) 的每个键都在封闭 schema 内 (additional_properties=reject, X-02);
3. (3) 对 (4) 的结果有否决权: 版本/记录数/字段范围超合同 -> 整体拒绝 + 安全事件 (R-05/X-03);
4. (4) 不信任 (3) 的转述: 每次调用独立重做四级鉴权 (R-03 三因用户面逐字节一致);
5. (5) 的受限内容物理上不可能进入响应 (字段枚举过滤; R-02 响应无备注内容);
6. (6) 与用户面隔离: 细分原因/安全事件不进用户封套 (R-03 no_reason_leak_to_user)。

## 有意不在边界内 (诚实边界)

- 真实网络/传输层/多租户并发 —— 教学实现为进程内确定性调用;
- 政策知识库 —— 属第 12 周冻结 RAG 管线, 不在本工具边界内;
- 写路径 —— 不存在 (范围决定 A: 第 13 周只做只读工具周)。
